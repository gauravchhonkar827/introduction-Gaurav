## How to use

Download or create a folder and put all four files inside it.

The structure should be:

gurmesh-portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md

Then open `index.html` in your browser.

## GitHub Pages

To publish the website:

1. Create a new GitHub repository.
2. Upload `index.html`.
3. Upload `style.css`.
4. Upload `script.js`.
5. Upload `README.md`.
6. Go to:

Settings → Pages

7. Select:

Deploy from a branch

8. Select:

main

9. Select:

/ (root)

10. Click Save.

Your website will then be available through your GitHub Pages URL.
